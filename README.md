# Smart Crop Recommendation System 🌾

An ML model that recommends the most suitable crop to grow based on soil and weather parameters.

## 📊 Features Used
- Nitrogen (N), Phosphorus (P), Potassium (K)
- Temperature (°C)
- Humidity (%)
- pH
- Rainfall (mm)

## 📁 Dataset
[Kaggle - Crop Recommendation Dataset](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset)

## ⚙️ Model
- Algorithm: Random Forest Classifier
- Accuracy: ~98% on validation set

## 🚀 How to Run
```bash
pip install -r requirements.txt
python crop_recommender.py
```

## 📦 Output
Displays the predicted crop for sample inputs.

## ✨ Example
```bash
Recommended Crop: rice
```
